--------------------------------------------------------------------------------
DESCRIPTION
--------------------------------------------------------------------------------
A secure, offline TOTP (Time-based One-Time Password) authenticator extension
for Microsoft Edge. Generates 2FA codes fully compatible with Google
Authenticator, Authy, and any RFC 6238 compliant authenticator app.
All secrets are stored locally using browser-encrypted storage — no data is
ever transmitted to any server.
