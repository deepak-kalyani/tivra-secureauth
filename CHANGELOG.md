## [1.0.0] - 2026-03-15

### Added
- Initial release of Tivra SecureAuth
- TOTP code generation (RFC 6238 / HMAC-SHA1) — fully offline
- Import accounts from Google Authenticator via QR export URL paste
- Live 30-second countdown timer with urgent warning (red) at 7 seconds
- One-click copy to clipboard
- Rename any account
- Delete accounts
- Persistent storage via `chrome.storage.local`
- Privacy policy page
- Compatible with Google Authenticator, Authy, Microsoft Authenticator, and all TOTP services
